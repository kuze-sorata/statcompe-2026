# 採用テーマ方針

## 仮題

**見えていない未来は選べない――地域による若者の「選択肢の可視性」格差**

## 論文の核

若者が選べる進路や生き方は、本人の能力や意欲だけで決まらない。大学、外国人、留学生、文化、学習、国際交流などとの接触によって、それまで知らなかった未来が「自分にも選べる選択肢」として見えるようになる。

制度上は誰でも県外進学や留学へ挑戦できても、地域によって外部の世界と接触する機会が異なれば、若者が想像できる未来の範囲にも格差が生じる可能性がある。本研究では、この格差を「選択肢の可視性格差」と捉える。

## 研究動機

本人は、留学生の多い大学への進学、友人から国際交流の場へ誘われた経験、英語学習、オーストラリアでの生活を通じて、海外や異なる価値観を段階的に自分の選択肢として認識した。最終的な進路が最初から見えていたのではなく、人との出会いが次の世界を順番に可視化した。

この経験から、本当は別の進路や経験を望み得た若者が、選択肢の存在を知らないために挑戦できない問題を検証する。

## 中心的な問い

外国人、大学、文化、学習、国際交流などへの接触機会が多い地域ほど、若者は地域外・海外を含む多様な進路や活動を、自分にも可能な選択肢として認識し、実際に選んでいるか。

想定する作用経路は次のとおりである。

```text
地域に存在する機会
        ↓
人・施設・活動との実際の接触
        ↓
自分にも可能だという選択肢の認識
        ↓
学習、進学、留学、地域外活動などの行動
```

## 測定・分析上の原則

「海外で学びたい」「地域外で働きたい」「将来には多くの可能性がある」など、選択肢の認識を直接測る指標を用いる。直接指標を利用できない場合は、英語・外国語学習、留学、県外進学、海外経験、文化・自己啓発活動など、選択肢が可視化された後に現れる行動を代理指標とする。

SSDSEは、外国人人口、大学、外国語学習、文化・芸術活動、海外旅行、図書館・公民館、所得、人口密度など、地域の機会環境と住民の行動を測るために用いる。

分析では「都市は施設が多い」という確認で終わらず、機会の存在が実際の接触や行動へ変換されているかを検討する。地域集計データだけで個人の認識変化を直接証明できない場合は、その限界を明示し、選択肢の可視性を表す代理指標として解釈する。
