# Project Requirements

## Competition

- 名称: 統計データ分析コンペティション2026
- 受付番号: U260042
- 受付区分: 大学生・一般の部
- 受付日: 2026-06-01
- 論文提出期限: 2026-08-28 12:00

## Submission Files

| 提出物 | ファイル名 | 形式・制限 |
| --- | --- | --- |
| 論文 | `U260042.pdf` | 原則PDF。本文2ページ以上8ページ以内、表紙を含め3ページ以上9ページ以内 |
| 要旨 | `U260042-abstract.pdf` | 1ページ以内。目的、手法、結論、意義を記載 |
| 論文提出・確認書 | `U260042-kakunin.xlsx` | 公式様式のExcelファイル |

- 3ファイルをメールに直接添付する
- 送信ファイルは10MB以内とする
- PDFにフォントを埋め込み、文字を画像化しない
- メール件名に受付番号 `U260042` を記載する

## Paper Format

- 公式の `ronbun-2026.docx` を執筆の正本とする
- 用紙はA4縦、上下左右の余白は20mm程度とする
- 本文は1段組、本文の書体は明朝体、10～10.5pt程度、行間は1行とする
- 表紙には論文タイトル、氏名、所属先のみを記載する
- 本文の先頭に論文タイトルを再掲し、氏名と所属先は記載しない
- ページ番号を用紙下端に記載する
- 表のキャプションは表の上側中央、図のキャプションは図の下側中央に置く
- 図表は白黒印刷でも判別できる配色・網掛けとする

## Recommended Paper Structure

1. 研究のテーマと目的
2. 研究の方法と手順
3. データセットの加工
4. データ分析の結果
5. 結果の解釈、分析の妥当性・限界、課題解決策、結論
6. 参考文献

## Analysis Requirements

- SSDSEのデータを1項目以上使用する
- SSDSE以外のデータを使う場合は出典を明記する
- 使用したSSDSEの種類と年次を明記する
- 課題、データの選定根拠、分析過程、結果、解決策を論理的につなげる
- 統計手法と可視化の適切性を確認する
- 参考研究、参考文献、データ出典を記録する
- 審査用の基データを提出できるよう、取得元と加工過程を保存する

## Codex Usage

Codexは、テーマ・仮説・分析計画の検討、データの取得と加工、分析・可視化コードの作成、統計手法の検証、ユーザーが書いた文章のレビューに使用する。提出する論文本文と要旨はユーザー自身が執筆する。
