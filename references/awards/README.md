# 過去受賞論文コーパス

統計データ分析コンペティションの公式サイトで公開されている2018〜2025年度の資料を収録する。

## 収録範囲

- 受賞論文: 159本（高校生の部77本、大学生・一般の部82本）
- 論文審査会総評: 9ファイル
- 年度: 2018〜2025年度
- 賞: 総務大臣賞、優秀賞、統計数理賞、統計活用奨励賞、旧名称の各賞、特別賞、審査員奨励賞

## ファイル

- `../manifests/awards.csv`: 公式URL、保存先、取得日時、SHA-256を含む取得台帳
- `index.csv`: 論文単位のメタデータ、本文抽出量、自動テーマ・手法タグ
- `notes/<year>/<division>/`: 1論文1ファイルの読書カード
- `cross-year-synthesis.md`: 年度横断の読み取りと、自分の分析への含意
- `raw/`: 公式PDF原本（Git管理外）
- `text/`: PDFからの抽出本文（Git管理外）

## 注意

テーマ・手法タグと「本文抽出メモ」は機械的な索引であり、精読結果ではない。論文を参照するときは、読書カードから公式PDFへ戻り、分析単位、変数定義、仮定、結果、限界を確認する。

再取得は `uv run python scripts/download_awards.py`、再索引は `uv run python scripts/build_award_corpus.py` で行う。
