# 受賞水準ベンチマーク

## 判定レベル

| レベル | 意味 |
| --- | --- |
| 0 未着手 | 判断材料がない |
| 1 基礎 | 要素はあるが、根拠・接続・検証が不足 |
| 2 応募水準 | 読者が分析と主張を追え、主要な欠陥がない |
| 3 受賞候補 | 独自性、実証の厳密さ、提案の価値が一体化 |

## 評価項目

| 項目 | レベル3の基準 |
| --- | --- |
| 問い | 具体的で検証可能、社会的重要性と対象範囲が明確 |
| 独自性 | 先行研究との差分を対象・データ・設計・示唆のいずれかで明示 |
| データ | 出典、単位、期間、欠測、外れ値、加工を説明し、選定理由がある |
| 仮説 | 理論・制度・既存知見から導き、変数と期待方向に接続 |
| 手法 | 問いとデータ構造に適合し、仮定と限界を説明 |
| 診断 | 残差、外れ値、共線性、代替仕様、異質性を目的に応じて確認 |
| 解釈 | 効果量と不確実性を示し、相関・予測・因果の範囲を守る |
| 提案 | 結果に支えられ、対象・実施主体・作用経路・期待効果が具体的 |
| 図表 | 一図一主張で、白黒でも判別でき、単位・注記・出典が完備 |
| 構成 | 問い、方法、結果、考察、提案、限界が一つの論証として接続 |
| 再現性 | 原データから主要図表までコードと台帳で再現可能 |
| 説明責任 | 執筆者が全ての選択と出力を自分の言葉で説明可能 |

## レビュー実施時点

テーマ採択、EDA完了、主分析確定、初稿、提出前の5回で評価する。各回は全項目を0〜3で記録し、合計点よりもレベル1以下の項目を優先して改善する。
